a-plus-b-vietnamese-demo

<<<PART: name>>>
Tổng hai số

<<<PART: lengend>>>
Cho hai số nguyên $a$ và $b$. Hãy tính tổng $a+b$.

<<<PART: input>>>
Một dòng gồm hai số nguyên $a$ và $b$, với $-10^9 \le a,b \le 10^9$.

<<<PART: output>>>
In ra một số nguyên là tổng của $a$ và $b$.

<<<PART: note>>>
Trong ví dụ, $2+3=5$.

<<<PART: solution>>>
#include <iostream>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    long long a, b;
    if (!(std::cin >> a >> b)) {
        return 1;
    }
    std::cout << a + b << '\n';
}
